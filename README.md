# pranith-website

My personal site. Every job and project is a holographic trading card you can tilt, flip over, or pull from a pack.

It's a single `index.html` with no build step and no dependencies. To run it locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder and go to http://localhost:8000.

To change the text, edit the data near the top of the script in `index.html` (`ME`, `WORK`, `PROJECTS`, `SKILLS`).
