About

Hey, I'm Pranith.

I'm studying computer science and statistics at Purdue, and I graduate in May 2028. I’ve spent a lot of time working with C and C++, doing things such as building my own version of a UNIX shell and doing some work with CUDA and GPU programming. I've also done work in the ML space, deploying models for weed detection in drone imagery and programming my own inference engine. Through all these experiences, I’ve become really interested in distributed systems, machine learning (inference & infrastructure), and high performance software that can handle large amounts of data efficiently.

This summer I interned at WellSky, where I swapped out a pile of old UiPath bots for a Python platform that now runs hundreds of hospital data jobs a day. Before that I was writing CUDA for Purdue's quant club and teaching a model to find weeds in drone photos.

I'm looking for systems, infrastructure and ML roles. If that sounds like your team, I'd love to hear from you.
